# tech-demos

A running collection of small, self-contained tech demos, each inspired by something interesting bookmarked on X: roughly one a day, rebuilt as a focused MVP to see how the idea holds up in practice. Every demo lives in its own folder under `apps/<slug>/`, has its own `PLAN.md`, and starts with `bun install && bun run dev`. `tracking/seen-bookmarks.json` records which bookmarks were proposed, approved, or skipped, and agent rules are in `AGENTS.md`.
